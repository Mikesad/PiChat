## 已确认决策（不要再改）

1. **登录**：使用现有 MySQL 数据库，邮箱 + 密码登录；不做 Keycloak / OIDC / SSO / IdP / SCIM。MVP 单租户。
2. **知识库默认 ACL**：动态计算。新增 `knowledge_base_acls` 表；有效权限 = 知识库默认 + 文档例外；deny 优先；不物化到文档 ACL。增加 `knowledge_bases.acl_version` 用于缓存失效。
3. **模型配置**：用户级。每个登录用户都可以配置自己的 OpenCode Go / DeepSeek；模型列表和默认模型按用户隔离；API Key 服务端加密存储，浏览器只拿脱敏信息。
4. **文档存储**：本地磁盘，`UPLOAD_DIR=D:\PiChat\uploads`，不接 MinIO/S3。Worker 读取本地文件后上传给 RAGFlow。
5. **成员与组**：来自本地 MySQL，不使用 IdP。成员页的“IdP 只读同步”文案必须改掉；MVP 先种子数据，后续再做本地成员/组编辑和密码重置。
6. **垂直切片**：登录 → 单知识库/文档 → 文档 ACL → 用户级模型配置 → `kb.search` → SSE 回答 + 引用。先完成这条链路，再扩展。
7. **ACL 写权限**：`tenant_admin` + `knowledge_admin`；`member` / `security_admin` 只读。

## 硬约束

- `apps/web` 只做 UI 和 BFF，不直连 RAGFlow；API Key 永远不进浏览器。
- 所有查询显式带 `tenant_id`；`tenantId`、`userId`、`documentIds` 只能来自服务端会话，绝不接受前端或模型传入。
- ACL 是唯一事实源：检索前计算 `allowedDocumentIds` → RAGFlow 同时传 `dataset_ids` + `document_ids` → 检索后复核 → 引用展示前再复核。
- ACL 缓存 key 必须带 `acl_version`；权限变更后下一次调用立即生效。
- 开源 RAGFlow 只有 dataset 级权限，不要依赖它的权限 UI。
- Pi 内置的 `read/write/edit/bash` 必须禁用，只注册知识库工具；Runtime `cwd` 用隔离空目录。
- SSE 事件必须复用 `packages/shared/src/sse.ts`，不要另造格式。
- 模型配置 Key 必须服务端加密（`model_configs.encrypted_api_key`），不得明文入库、不得写日志。
- 不要手改 `packages/db/drizzle/` 下已生成的 SQL；Schema 改动后运行 `pnpm db:generate`。
- 不要提前做 MCP、CLI、多租户 SaaS、HA、RAGFlow Chat/Agent。
