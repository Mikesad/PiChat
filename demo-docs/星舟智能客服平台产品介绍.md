## 1. 产品概述

星舟智能客服平台是启元科技面向企业客户服务场景自研的一体化智能客服产品，覆盖电话、网页、App、微信、企业微信、抖音等全渠道咨询入口，提供智能机器人、人工坐席、工单流转、服务质检和运营分析能力。

平台采用“大模型 + 知识库 + 业务流程”的组合架构，既能独立完成高频问题的自动应答，也能在复杂场景下为人工坐席提供实时话术推荐、知识检索和自动摘要。产品支持公有云订阅、私有化部署和混合部署三种交付模式，已在零售、金融、政务、制造、教育等行业落地。

星舟智能客服平台的核心理念是“一次建设、全渠道复用、持续运营”。企业只需维护一套知识库和服务流程，即可在各渠道保持一致的服务体验，并通过数据看板持续优化机器人解决率和客户满意度。

## 2. 目标客户与典型场景

### 2.1 目标客户

- 日均咨询量在 500 通以上的中大型企业。
- 拥有多个线上渠道、需要统一服务标准的品牌方。
- 对数据安全有要求、需要私有化部署的金融、政务和医疗客户。
- 正在建设客服中心或计划替换传统呼叫中心的企业。

### 2.2 典型场景

1. **售前咨询**：机器人识别产品型号、价格、库存和促销政策，自动引导留资或转人工。
2. **售后服务**：根据订单号查询物流、退换货进度，自动创建工单并跟踪处理。
3. **坐席辅助**：通话或文字会话中实时推荐答案、提示合规话术、自动生成会话小结。
4. **服务质量检查**：按规则对全量会话进行自动质检，输出违规点和改进建议。
5. **运营分析**：统计咨询热点、机器人解决率、首响时长和满意度趋势。

## 3. 核心功能模块

### 3.1 全渠道接入

- 统一接入网页在线咨询、App SDK、微信公众号、小程序、企业微信、抖音私信、邮件和电话。
- 支持渠道级路由策略，可按业务线、客户等级、地域和时段分配坐席。
- 提供渠道健康监控，异常时自动告警并支持降级到留言或工单。

### 3.2 智能机器人

- 支持 FAQ、任务型多轮对话、文档问答和表格查询四种机器人能力。
- 内置意图识别、实体抽取、上下文记忆和多轮澄清机制。
- 知识库支持批量导入 Word、PDF、Markdown、TXT 和网页内容，导入后可在线预览与版本回滚。
- 支持设置转人工条件，例如连续两轮未解决、命中敏感词或客户主动要求。
- 提供机器人测试沙箱，配置变更可先在沙箱验证再发布。

### 3.3 人工坐席工作台

- 统一工作台处理全渠道会话，支持会话排队、转接、邀请协助和静默监听。
- 坐席侧实时展示客户画像、历史工单、订单信息和推荐知识。
- 内置快捷回复、常用语、话术库和敏感词提醒。
- 会话结束后自动生成摘要、情绪标签和后续待办。

### 3.4 工单与流程

- 支持工单模板、字段自定义、SLA 计时、自动分派和升级规则。
- 提供可视化流程编排，支持审批、回访、挂起和关闭等节点。
- 工单可与订单、CRM、ERP 等业务系统通过开放接口联动。

### 3.5 智能质检

- 支持全量自动质检与人工抽检相结合。
- 质检规则涵盖服务用语、响应时长、禁语、重复来电、客户情绪等维度。
- 自动生成坐席评分卡和改进建议，支持申诉与复核流程。

### 3.6 数据分析

- 提供实时监控大屏和离线分析报表。
- 核心指标包括咨询量、接通率、首响时长、平均处理时长、机器人解决率、转人工率和满意度。
- 支持按渠道、业务线、技能组、坐席和时间维度下钻分析。
- 支持自定义报表和指标订阅。

### 3.7 开放平台

- 提供 REST API、Webhook 和 SDK，支持会话、工单、客户和知识库数据集成。
- 支持单点登录、组织架构同步和消息推送。
- 提供接口调用监控、限流和审计日志。

## 4. 技术架构

平台采用分层微服务架构：

| 层次 | 组成 | 说明 |
| --- | --- | --- |
| 接入层 | API 网关、渠道适配器、WebSocket 服务 | 统一协议转换、鉴权、限流和会话保持 |
| 应用层 | 会话服务、坐席服务、工单服务、质检服务、分析服务 | 按业务域拆分，可独立扩缩容 |
| 能力层 | 机器人引擎、知识库、语音识别、语音合成、大模型适配 | 支持云端模型与私有化模型切换 |
| 数据层 | MySQL、Redis、Elasticsearch、对象存储、消息队列 | 业务数据、缓存、检索、附件与异步任务 |
| 运维层 | 容器平台、日志、监控、告警、审计 | 支持灰度发布与链路追踪 |

关键技术特性：

- 会话消息通过 WebSocket 长连接推送，断线后自动重连并补齐消息。
- 机器人与人工坐席共享同一套知识库和客户上下文，转人工时无需客户重复描述。
- 大模型调用可配置超时、重试、限流和内容安全策略。
- 所有敏感操作写入审计日志，日志保留时间可配置。

## 5. 部署与运行环境

### 5.1 部署方式

- **公有云订阅**：由启元科技统一运维，客户按坐席数和调用量订阅。
- **私有化部署**：部署在客户机房或专有云，支持离线安装。
- **混合部署**：核心数据留在本地，语音识别和大模型能力按需调用云端服务。

### 5.2 软件依赖

- 操作系统：CentOS 7.9、Rocky Linux 9、Ubuntu 22.04 或国产主流 Linux 发行版。
- 容器平台：Docker 24 及以上，Kubernetes 1.26 及以上。
- 数据库：MySQL 8.0（主从或 MGR）。
- 缓存：Redis 7.0 及以上。
- 检索：Elasticsearch 8.x。
- 消息队列：Kafka 3.x 或 RocketMQ 5.x。
- 对象存储：MinIO、阿里云 OSS、腾讯云 COS 或兼容 S3 协议的服务。
- 反向代理：Nginx 1.24 及以上。

### 5.3 服务器配置建议

| 环境 | 节点数 | 单节点配置 | 说明 |
| --- | --- | --- | --- |
| 试点环境 | 3 | 8 核 16 GB / 500 GB | 支持 50 坐席、日均 3000 次咨询 |
| 生产环境（中型） | 6 | 16 核 32 GB / 1 TB | 支持 300 坐席、日均 3 万次咨询 |
| 生产环境（大型） | 9 及以上 | 32 核 64 GB / 2 TB | 支持 1000 坐席以上，按需横向扩展 |

若使用私有化大模型，需要额外配置 GPU 节点，具体规格根据模型参数量和并发量评估。

### 5.4 网络与安全

- 对外仅暴露网关和 WebSocket 端口，内部服务通过集群内网通信。
- 支持 HTTPS、国密算法和双向证书认证。
- 支持 IP 白名单、登录双因素认证和会话超时策略。
- 数据存储支持透明加密，附件支持水印和下载审计。

## 7. 验收标准

1. 平台各模块可正常登录和操作，核心业务流程闭环。
2. 约定渠道全部接入，消息收发成功率达到 99.5% 以上。
3. 机器人对验收问题集的回答准确率达到 85% 以上。
4. 工单创建、流转、升级和关闭流程符合业务要求。
5. 与约定业务系统的接口联调通过，数据一致性校验无误。
6. 压力测试达到约定的并发坐席数和消息吞吐量。
7. 安全扫描无高危漏洞，审计日志完整可查。
8. 交付文档齐全，管理员和坐席培训完成。

## 10. 常见问题

**Q1：平台是否必须使用公有云大模型？**

不是。平台支持云端模型、私有化模型和混合模式，客户可根据数据合规要求选择。

**Q2：知识库文档更新后多久生效？**

文档解析完成后即可生效，通常单篇文档在 5 分钟内完成解析。解析失败时可在管理端查看原因并重新提交。

**Q3：能否只上线机器人，不建设人工坐席？**

可以。机器人可独立对外服务，后续再按需开通坐席工作台和工单模块。

**Q4：是否支持国产化环境？**

支持国产 Linux 发行版、国产数据库适配和国密算法，具体适配清单以项目评估结果为准。
