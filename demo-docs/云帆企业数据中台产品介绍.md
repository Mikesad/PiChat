## 1. 产品概述

云帆企业数据中台是启元科技自研的一站式数据建设与治理平台，面向企业数据分散、口径不一致、取数效率低和分析链路长等问题，提供数据集成、数据开发、数据治理、指标管理、自助分析和数据服务能力。

平台以“统一采集、统一建模、统一指标、统一服务”为建设主线，帮助企业将分散在各业务系统中的数据汇聚到统一的数据底座，形成可复用、可追溯、可运营的数据资产。云帆既支持传统数仓分层建模，也支持湖仓一体和实时数据处理。

云帆企业数据中台适用于正在推进数字化转型的中大型企业，尤其适合多业务线、多系统并存、数据团队与业务团队协同频繁的组织。

## 2. 目标客户与典型场景

### 2.1 目标客户

- 拥有多个业务系统、数据分散且口径不统一的企业。
- 已建设数据仓库，但缺乏治理体系和指标管理的企业。
- 希望将数据能力以 API 或报表形式开放给业务团队的企业。
- 需要实时数据支撑运营决策的零售、物流、金融和制造企业。

### 2.2 典型场景

1. **经营分析**：统一销售、库存、财务和客户指标，支撑管理层经营看板。
2. **实时运营**：接入订单、物流和支付数据，实现分钟级运营监控。
3. **客户洞察**：整合会员、交易和行为数据，输出客户分群与生命周期标签。
4. **监管报送**：建立可追溯的数据血缘和质量校验，满足合规报送要求。
5. **数据服务化**：将加工后的数据以 API 形式开放给 CRM、营销和风控系统。

## 3. 核心功能模块

### 3.1 数据集成

- 支持关系型数据库、文件、消息队列、API 和对象存储等数据源。
- 提供全量同步、增量同步和实时 CDC 三种接入方式。
- 支持可视化配置字段映射、清洗规则和调度周期。
- 内置任务监控、失败重试、断点续传和告警通知。

### 3.2 数据开发

- 提供 SQL 开发、可视化工作流和脚本任务三种开发模式。
- 支持离线调度、实时计算和依赖编排。
- 提供开发、测试和生产多环境隔离，支持版本管理和发布审批。
- 内置代码检查、资源预估和任务基线监控。

### 3.3 数据建模

- 支持维度建模、宽表建模和湖仓分层建模。
- 提供模型设计器、字段标准引用和模型变更影响分析。
- 支持贴源层、明细层、汇总层和应用层的数据组织。
- 模型发布后自动生成血缘关系和技术元数据。

### 3.4 数据治理

- 提供元数据管理、数据标准、数据质量、数据安全和数据生命周期管理。
- 质量规则支持唯一性、完整性、及时性、有效性和自定义 SQL 校验。
- 质量问题可自动生成工单并通知责任人。
- 支持敏感数据识别、分级分类、脱敏规则和访问审计。
- 提供数据血缘图谱，支持字段级追溯和影响分析。

### 3.5 指标管理

- 统一管理原子指标、派生指标和复合指标。
- 指标定义包含业务口径、计算逻辑、数据来源、责任人和生效时间。
- 支持指标版本管理和变更审批，避免口径随意变更。
- 指标可自动生成查询 API 和报表数据集。

### 3.6 自助分析

- 业务人员可通过拖拽方式制作图表和看板，无需编写 SQL。
- 支持明细表、透视表、趋势图、漏斗图、地图等多种可视化组件。
- 提供数据集权限、行级权限和列级权限控制。
- 看板支持订阅、导出、分享和移动端查看。

### 3.7 数据服务

- 将数据表、指标和查询逻辑发布为标准化 API。
- 支持访问申请、审批、限流、缓存和调用监控。
- 提供 API 文档、SDK 示例和在线调试。
- 支持按应用、用户和数据范围进行授权。

## 4. 技术架构

云帆采用存算分离和湖仓一体架构：

| 层次 | 组成 | 说明 |
| --- | --- | --- |
| 数据接入 | CDC、批量同步、文件采集、消息接入 | 支持结构化与半结构化数据 |
| 存储计算 | 数据湖、MPP 数据库、实时计算引擎 | 按场景选择离线或实时链路 |
| 平台服务 | 元数据、调度、开发、治理、指标、服务 | 统一租户、权限和审计 |
| 应用层 | 自助分析、数据门户、开放 API | 面向业务用户和数据消费者 |
| 运维层 | 监控、告警、日志、资源管理 | 支持多集群和弹性扩缩容 |

关键技术特性：

- 支持 Hadoop、Spark、Flink、Doris、ClickHouse 等主流组件的组合部署。
- 支持存算分离，计算资源可按任务负载弹性伸缩。
- 元数据与血缘统一采集，覆盖表、字段、任务和指标。
- 平台自身不绑定特定云厂商，可在私有云、公有云和混合云环境运行。

## 5. 部署与运行环境

### 5.1 部署方式

- **私有化部署**：部署在客户机房或专有云，适合数据敏感型企业。
- **专有云部署**：部署在客户指定的云账号和 VPC 内，由客户自主管理。
- **托管服务**：由启元科技提供运维托管，客户按资源和使用量付费。

### 5.2 软件依赖

- 操作系统：Rocky Linux 9、Ubuntu 22.04 或国产主流 Linux 发行版。
- 容器平台：Kubernetes 1.26 及以上。
- 元数据库：MySQL 8.0 或 PostgreSQL 15。
- 缓存：Redis 7.0 及以上。
- 对象存储：MinIO、OSS、COS 或兼容 S3 协议的服务。
- 调度与消息：Kafka 3.x、ZooKeeper 3.8。
- 计算引擎：Spark 3.5、Flink 1.18、Doris 2.1 或 ClickHouse 24.x，按项目选型。

### 5.3 服务器配置建议

| 环境 | 节点数 | 单节点配置 | 说明 |
| --- | --- | --- | --- |
| 试点环境 | 3 | 8 核 32 GB / 1 TB | 支持 20 个数据源、日均 100 个任务 |
| 生产环境（中型） | 6 | 16 核 64 GB / 2 TB | 支持 100 个数据源、日均 1000 个任务 |
| 生产环境（大型） | 9 及以上 | 32 核 128 GB / 4 TB | 支持大规模湖仓与实时链路，按需扩展 |

计算节点和存储节点可分离部署；实时链路建议独立部署 Flink 集群，避免与离线任务争抢资源。

### 5.4 网络与安全

- 平台服务与计算集群部署在独立安全域，通过防火墙限制访问来源。
- 支持 Kerberos、LDAP、OAuth 2.0 和单点登录集成。
- 数据传输支持 TLS，敏感字段支持加密存储和动态脱敏。
- 所有数据访问行为记录审计日志，支持按用户、表和时间检索。

## 7. 验收标准

1. 约定的数据源全部接入，同步任务按计划稳定运行。
2. 数据完整性、及时性和准确性校验达到约定标准。
3. 核心指标口径通过业务部门确认，指标字典完整。
4. 数据血缘覆盖核心模型和指标，可追溯到源系统字段。
5. 权限体系生效，用户只能访问授权范围内的数据。
6. 自助分析看板可正常使用，查询响应满足约定性能指标。
7. 数据服务 API 通过联调和压力测试。
8. 交付文档和培训完成，运维团队可独立执行日常操作。

## 10. 常见问题

**Q1：云帆是否要求替换现有的数据仓库？**

不要求。云帆可以接管现有数仓的调度、治理和指标管理，也可以与现有数仓并行建设，逐步迁移。

**Q2：实时数据和离线数据能否统一管理？**

可以。实时链路和离线链路共用元数据、指标和权限体系，血缘可跨链路追溯。

**Q3：业务人员需要学习 SQL 吗？**

不需要。自助分析支持拖拽式操作，复杂分析可由数据团队先建设数据集再开放给业务人员。

**Q4：平台是否支持信创环境？**

支持国产操作系统、国产数据库和国产大数据组件适配，具体清单需在项目调研阶段确认。
